      About and privacy

      The company feed is encrypted with your batch's key, which travels in the link after the # (browsers never send that part to a server). The key is membership gating, so the feed is "not public"; it is not a secret, since anyone in the batch can pass the link on.

      Your personal data (statuses, notes, CV text, identifiers, pasted schedules) stays on this device. It leaves only as ciphertext: in a backup file you export, or, if you turn sync on, as one encrypted file in a secret gist in your own GitHub account. The sync code that encrypts it never goes to GitHub.

      No accounts, no analytics, no third-party scripts or fonts. Shortlist checks keep only your own matches and the schedule rows, never other students' names. The CV match runs here.

      Not an official OCCaP service: always confirm dates from the OCCaP mail.
